# NOVARA — Backend REST API (Node.js + Express + MongoDB)

This is the backend REST API server for the **NOVARA** luxury e-commerce platform.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env with your MongoDB URI, JWT secret, and port

# 3. Start server
npm start
```

For complete architecture, features, API documentation, and configuration instructions, please refer to the [Root README](../README.md).
