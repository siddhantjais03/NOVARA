# NOVARA — Frontend Client (React 19 + Vite)

This is the frontend client application for the **NOVARA** luxury e-commerce platform.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment (optional, defaults to http://localhost:5000/api)
cp .env.example .env

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```

For complete architecture, features, API documentation, and configuration instructions, please refer to the [Root README](../README.md).
